### Most of my work sits in two lanes: product engineering in TypeScript and Next.js, and native desktop or security tooling in Rust and Node.js.

I'm a software engineering student in Gujarat who builds user-facing products, from web interfaces to local-first desktop software. I focus on making them clear to use on the surface and dependable underneath.

### Shipped Work

* **[Draft](https://draft.tirup.in)** ([`draft-rs`](https://github.com/TirupMehta/draft-rs)): Private, on-device dictation for Windows built with Rust and GPUI. Hold Right Ctrl, speak, and release: Whisper `large-v3-turbo` runs locally over Vulkan (239 ms p95 latency on a 3s clip) with no account, no audio upload, and no telemetry.
* **[ModelRegistry](https://modelregistry.tirup.in)** ([source](https://github.com/TirupMehta/ModelRegistry)): Open, machine-readable registry tracking 29 frontier AI models across 14 labs, served through a public REST API, RSS feed, and live status badges.
* **[trace-guard](https://www.npmjs.com/package/trace-guard)** ([source](https://github.com/TirupMehta/trace-guard)): Edge behavioral security middleware on npm (`v3.7.0`) that detects and blocks headless browsers, CDP automation, and VLM-driven agents.
* **[Archive](https://archive.tirup.in)** ([source](https://github.com/TirupMehta/archive)): Minimalist writing app built with Next.js, TypeScript, and TipTap with real-time cloud sync.
* **[opencode-usage](https://github.com/TirupMehta/opencode-usage)**: Zero-dependency local dashboard for inspecting OpenCode token usage and session costs.
* **[GleanBox](https://github.com/TirupMehta/GleanBox)**: Chrome extension for capturing web snippets and retrieving them by keyword.

### Core Stack

* **Product & Frontend:** TypeScript, JavaScript, React, Next.js, Tailwind CSS, Motion, shadcn/ui, Base UI
* **Systems & Desktop:** Rust, GPUI, local GPU inference (`transcribe.cpp` / Whisper over Vulkan), Node.js
* **Backend & Data:** Convex, Supabase, Redis, MongoDB, Cloudflare Workers
* **Security & Reliability:** Content Security Policies (CSP), Web Crypto / AES-GCM, behavioral bot detection, zero-network build hardening
